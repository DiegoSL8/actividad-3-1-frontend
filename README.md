# Introducción a JS en Desarrollo Frontend (Actividad 3.1)

Este repositorio contiene la resolución de la Actividad 3.1, centrada en la manipulación del Document Object Model (DOM) y el manejo de eventos utilizando JavaScript Vanilla. 

Se aplicó el principio de "Separación de Responsabilidades", dividiendo la manipulación visual de la lógica de validación.

##  Requerimientos Cumplidos

- [x] Interfaz HTML/CSS limpia, estructurada y responsiva.
- [x] **Arquitectura Modular:** Separación de UI (`dom.js`) y lógica de negocio (`script.js`).
- [x] Manipulación del DOM para inyección dinámica de mensajes y toggle de clases.
- [x] Validación de campos vacíos.
- [x] Validación de correo electrónico estricta mediante Expresiones Regulares (Regex).
- [x] Limpieza del formulario y mensaje de éxito temporizado (`setTimeout`).
